# User Commands

- `/start` - запуск, заявка на доступ, главное меню.
- `/voices` - активные голоса.
- `/setvoice` - интерактивный выбор голоса.
- `/balance` - общий Hedra balance.
- `/help` - справка.

Кнопки меню:
- `🎙 Текст → аудио`
- `🖼 Текст + фото → видео`
- `🎧 Аудио + фото → видео`
- `🎭 Голос`
- `📊 Баланс`
